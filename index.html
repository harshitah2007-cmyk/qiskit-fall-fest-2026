01 / The project

From ECG signal to classification

We explore whether a small variational quantum circuit can learn a binary heartbeat classification task, and compare its results with a classical baseline.

⌁

Biomedical signal data

ECG beat windows are represented using statistical features from the MIT-BIH Arrhythmia Database. The project groups the selected beat labels into normal and abnormal classes.

◈

Quantum model

Features are scaled and reduced to four components before encoding them into a four-qubit feature map and trainable variational ansatz.

↗

Baseline & circuit study

A logistic regression baseline provides context for model performance. Processor A and B coupling maps are inspected using transpiled circuit-resource metrics.
